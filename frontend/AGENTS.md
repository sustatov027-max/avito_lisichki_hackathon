# Инструкции для Codex

## Стек проекта

- Node.js + React, TypeScript.

## Правила экономии токенов (Strict Limits)

1. Пиши код максимально кратко, без длинных текстовых объяснений, если я сам о них не попрошу.
2. Не генерируй заново весь файл, если изменения затрагивают только одну функцию. Выводи только измененный diff/фрагмент.
3. Не надо задавать компонентам focus-visible, я это уже сделал глобально
4. Не деструктурируй props const Example = (здесь) => { ... }, делай это const Example = (props) => {
   const {так} = props
   }
5. Когда пишешь стили используй все инструменты SCSS которые я сделал, они лежат в src/shared/styles, и в src/app/styles.
6. Не пиши в начале файла SCSS @use '@shared/styles/helpers' as *;
7. Если это компонент можно анимировать, то используй анимацию сдеражнно, и используй для этого framer-motion.
8. В shared/ui/index.ts файл не нужно экспортировать типы пропсов компонентов
